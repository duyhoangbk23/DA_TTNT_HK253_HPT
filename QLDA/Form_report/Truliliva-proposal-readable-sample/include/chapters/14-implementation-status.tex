\section{Mức xác minh}

Ma trận kết hợp snapshot source với kết quả live test của luồng telemetry. Live test đã
xác nhận MCU, HiveMQ, Device Monitor và MySQL hoạt động đồng thời: payload được publish,
Device Monitor ingest thành công và bản ghi tương ứng được lưu trong bảng
\texttt{telemetry}. Các trạng thái khác chỉ được đánh giá theo evidence source khi chưa
có xác nhận runtime riêng.
