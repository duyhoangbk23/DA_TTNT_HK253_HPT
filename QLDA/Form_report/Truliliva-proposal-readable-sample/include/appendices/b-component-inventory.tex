\section{Điểm không đồng bộ ảnh hưởng inventory}

\begin{itemize}
  \item Migration \path|2026_07_13_000000_create_telemetry_table.php| là nguồn chuẩn; \path|telemetry.mcu_id| là chuỗi có index riêng và index với timestamp (E-DB-02).
  \item Simulator, Device Monitor và Laravel telemetry API đã dùng \path|mcu_id| (E-SIM-03, E-DM-03, E-ADM-05).
  \item Firmware chính và .NET worker còn dùng \path|device_id|; worker ghi vào \path|device_data| theo \path|Database/init.sql|. Vì vậy không có bằng chứng cho thấy hai thành phần này tương thích end-to-end với schema chuẩn hiện tại (E-FW-04, E-MQ-03, E-MQ-05).
  \item \path|app/Services/TelemetryService.php| của Admin hiện là file rỗng; luồng ingest được thực hiện trực tiếp trong controller. File rỗng không được tính là một service đã triển khai (E-ADM-06).
\end{itemize}
