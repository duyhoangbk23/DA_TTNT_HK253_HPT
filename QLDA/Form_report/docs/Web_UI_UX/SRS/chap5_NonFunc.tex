\chapter{Non-functional Requirements}

This chapter specifies the non-functional requirements of the Water Purifier Maintenance Management System. These requirements define the quality attributes and operational constraints of the software rather than specific business functions.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{Performance Requirements}

The system shall provide acceptable performance under normal operating conditions.

\begin{itemize}
    \item NFR-001 The system shall load each web page within 3 seconds under normal network conditions.
    \item NFR-002 The system shall support at least 20 concurrent users without noticeable performance degradation.
    \item NFR-003 Database queries for standard operations shall return results within 2 seconds.
    \item NFR-004 Dashboard statistics shall be generated within 5 seconds.
\end{itemize}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{Security Requirements}

The system shall ensure that user information and business data are protected.

\begin{itemize}
    \item NFR-005 User authentication shall be required before accessing protected resources.
    \item NFR-006 Access permissions shall be controlled based on user roles.
    \item NFR-007 User passwords shall be securely stored using encrypted hashing algorithms.
    \item NFR-008 All communications between client and server shall use HTTPS in production environments.
    \item NFR-009 Unauthorized users shall not access restricted modules.
\end{itemize}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{Usability Requirements}

The application shall provide an intuitive and user-friendly interface.

\begin{itemize}
    \item NFR-010 The user interface shall follow a consistent layout across all pages.
    \item NFR-011 Navigation shall be accessible through a sidebar menu.
    \item NFR-012 Data tables shall support searching, sorting, filtering, and pagination.
    \item NFR-013 The interface shall provide clear validation messages for invalid input.
    \item NFR-014 The system shall use responsive web design principles.
\end{itemize}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{Reliability Requirements}

The system shall maintain stable operation during normal usage.

\begin{itemize}
    \item NFR-015 The application shall recover gracefully from unexpected errors.
    \item NFR-016 System exceptions shall be logged for troubleshooting.
    \item NFR-017 Database transactions shall maintain data consistency.
\end{itemize}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{Maintainability Requirements}

The system shall be designed for future maintenance and extension.

\begin{itemize}
    \item NFR-018 The application shall follow a modular architecture.
    \item NFR-019 Source code shall follow consistent coding conventions.
    \item NFR-020 Business logic shall be separated from the presentation layer.
    \item NFR-021 Database design shall support future expansion.
\end{itemize}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{Compatibility Requirements}

The application shall operate correctly on common platforms.

\begin{itemize}
    \item NFR-022 The system shall support Google Chrome, Microsoft Edge, and Mozilla Firefox.
    \item NFR-023 The user interface shall support desktop, tablet, and mobile devices.
    \item NFR-024 The application shall support screen resolutions of 1366×768 and above.
\end{itemize}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{Availability Requirements}

The demonstration system shall remain available during development and testing.

\begin{itemize}
    \item NFR-025 The system shall be available whenever the web server is operational.
    \item NFR-026 Users shall be informed if the system is temporarily unavailable.
\end{itemize}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{Scalability Requirements}

The software architecture shall support future system expansion.

\begin{itemize}
    \item NFR-027 The architecture shall allow additional management modules to be integrated.
    \item NFR-028 The database shall support increasing numbers of customers and devices.
    \item NFR-029 The system shall support future integration with real-time IoT monitoring services.
\end{itemize}
