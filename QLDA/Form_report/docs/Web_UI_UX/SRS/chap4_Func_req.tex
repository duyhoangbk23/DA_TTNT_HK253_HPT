\chapter{Functional Requirements}

This chapter describes the functional requirements of the Water Purifier Maintenance Management System. Each functional module specifies the expected behavior and capabilities that the software shall provide.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{FR-01 Dashboard}

\subsection*{Description}

The Dashboard provides an overview of the system by presenting business statistics and recent activities.

\subsection*{Functional Requirements}

\begin{itemize}
    \item FR-01.1 The system shall display the total number of customers.
    \item FR-01.2 The system shall display the total number of products.
    \item FR-01.3 The system shall display the total number of installed devices.
    \item FR-01.4 The system shall display the number of active contracts.
    \item FR-01.5 The system shall display maintenance statistics.
    \item FR-01.6 The system shall display recent activities.
    \item FR-01.7 The system shall display recent maintenance operations.
\end{itemize}

\section{FR-02 Product Management}

\subsection*{Description}

The Product Management module allows administrators to manage water purifier products.

\subsection*{Functional Requirements}

    \item FR-02.3 The system shall allow users to delete products.
    \item FR-02.4 The system shall display product details.
