\section{Nhận xét cấu trúc có bằng chứng}

\begin{itemize}
  \item SmartWater Admin autoload factory và seeder từ dự án \texttt{smartwater-database}; \path|migrate.bat| chạy migration tại đó, vì vậy migration là nguồn chuẩn của schema dùng chung (E-DB-01, E-ADM-03).
  \item Device Monitor là ứng dụng độc lập với SmartWater Admin. Nó tự mở kết nối PDO, cung cấp route Slim và kiểm tra bảng telemetry khi khởi động; việc tạo schema thuộc migration dùng chung (E-DM-02, E-DM-05).
  \item \texttt{SmartWater.MqttService} có schema SQL riêng gồm \texttt{devices} và \texttt{device\_data}; schema này không phải migration Laravel hiện tại (E-MQ-05, E-DB-02).
  \item Source chứa cấu hình MQTT ở phía client nhưng không tìm thấy manifest triển khai HiveMQ broker trong các ranh giới dự án nêu trên. Broker vì vậy được xem là phụ thuộc bên ngoài đã cấu hình, không phải thành phần được triển khai bằng repository này (E-MQ-06).
\end{itemize}
